品牌站前端开源

品牌站的前端代码已在 GitHub 公开，采用 MIT 许可，v1.0.0 同步发布。

公开了什么

仓库在 github.com/fengderenzhui-lab/nalide-website。构建本站的全部前端源码都在里面：页面与组件、样式、构建与预渲染脚本、冒烟测试、代码规范与持续集成配置。技术上是 React + Vite + TypeScript + Tailwind 的一套现代前端，克隆下来就能跑。

为什么开源

一是透明：我们嘴上说重视安全与规范，代码摆出来，任何人都能检查这句话的成色。二是给同行留个参考：预渲染、全仓 SPDX 许可标注（通过 FSFE REUSE 合规检查）、无障碍这些不起眼的功夫，都写在代码里。

边界

开源的是代码。NALIDE 的名称与 Logo、站内图片、品牌文案不随代码授权；字体按各自的开源许可（SIL OFL 1.1）。这条边界写在仓库 README 的最前面，不藏着。

怎么参与

欢迎围观、提 issue 或 PR，贡献方式见仓库的 CONTRIBUTING。唯独安全问题例外：请走漏洞披露政策私下报告，不要公开提 issue。

联系：contact@nalide.com
